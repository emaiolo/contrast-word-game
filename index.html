Instructions and source

Guess the five-letter word in six tries. A black tile means the letter is in the right spot. Striped means the letter is in the word but in the wrong spot. An X means the letter is not used in that position and is not needed beyond any matching letters elsewhere. Type with the on-screen keyboard or a physical keyboard. Only recognized five-letter English words are accepted. Unrecognized guesses do not use an attempt. The dictionary includes uncommon words.

This independent accessibility prototype uses the NYT daily puzzle answer, fetched by a GitHub workflow. It is not affiliated with or endorsed by The New York Times. Puzzle data requires a successful daily update. No daily answers are shown unless you finish the game.

Progress is saved only on this device. Date follows the device's local calendar day.

Puzzle not loading?

To publish with GitHub Pages, choose Settings → Pages → Build and deployment → GitHub Actions. Then run Actions → Update daily puzzle and publish → Run workflow. Scheduled updates ordinarily run each day, but GitHub may delay them.

If fetching fails, manually enter the answer from a trusted source without letting the player see it. This is stored only in this browser for that date.
